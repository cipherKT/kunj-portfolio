## Overview

Aurora UI is a design system and component library built for consistency, accessibility, and speed across projects.

## Key Features

- Composable primitives — buttons, inputs, modals, tooltips
- Dark mode first, theming via CSS custom properties
- WAI-ARIA compliant, keyboard navigable

## Stack

- React, TypeScript, CSS Modules
